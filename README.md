# CLI Product Manager

A lightweight, console-based product management application built purely in **C#** and **.NET**. 

---

## Project Purpose

This is a **learning and portfolio project** designed to demonstrate core C# programming concepts, object-oriented design patterns, terminal input handling, and local data persistence. It is meant as a hands-on exploration of C# fundamentals rather than a production-ready software product.

---

## Concepts & Architectural Focus

* **Object-Oriented Programming (OOP):** Encapsulation of product models, inheritance, interface-driven service design.
* **LINQ & In-Memory Querying:** Filtering, sorting, and searching products dynamically using C# Language Integrated Query.
* **Data Persistence:** Lightweight JSON serialization for reading and writing product state to a local file.
* **Console I/O & Validation:** Robust input parsing, exception handling, and user-friendly error messages for command-line arguments.
* **Clean Code Structure:** Logical separation between the Console UI layer, application services, and data storage logic.

---

## Demonstrated Features

* **View Catalog:** List all products with formatted console output.
* **Search & Filter:** Find products by keyword, category, or price range.
* **Inventory Management:** Add, update, or remove product entries.
